# The protocol of a recorded test in one line

The protocol of a recorded test in one line

## Usage

``` r
recording_protocol(fields, sport)
```

## Arguments

- fields:

  The fields of the recording form.

- sport:

  The sport.

## Value

a string such as "Lode Excalibur, 3-min stages of +25 W from 50 W,
earlobe whole blood, Biosen C-Line", or `NULL` when nothing was
recorded.
