# Lactate thresholds by group

Runs
[`lactate_threshold()`](https://fmmattioni.github.io/lactater/reference/lactate_threshold.md)
once per group and binds the results, with the group columns first. For
internal use only.

## Usage

``` r
lactate_threshold_by(.data, .by, arguments)
```

## Arguments

- .data:

  The raw data.

- .by:

  The grouping column names.

- arguments:

  The other
  [`lactate_threshold()`](https://fmmattioni.github.io/lactater/reference/lactate_threshold.md)
  arguments.
