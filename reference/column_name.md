# Column name from a bare name, a string, or a variable that holds a string

Column name from a bare name, a string, or a variable that holds a
string

## Usage

``` r
column_name(expr, .data, env)
```

## Arguments

- expr:

  The captured argument.

- .data:

  The data.

- env:

  Where to look up a variable.

## Value

the column name, or `NULL`.
