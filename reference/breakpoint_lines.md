# The straight lines of a breakpoint fit

The straight lines of a breakpoint fit

## Usage

``` r
breakpoint_lines(fit)
```

## Arguments

- fit:

  A fit from
  [`fit_breakpoints()`](https://fmmattioni.github.io/lactater/reference/fit_breakpoints.md)
  or
  [`fit_two_lines()`](https://fmmattioni.github.io/lactater/reference/fit_two_lines.md).

## Value

a list of functions, one line per segment, each defined over all `x`.
