# A secondary point with a small label

A secondary point with a small label

## Usage

``` r
other_point(x, y, label, colours)
```

## Arguments

- x, y:

  Where the point sits.

- label:

  The label below it, as plotmath (a quoted string, or e.g.
  `"LT"[ratio]`).

- colours:

  The plot colours.
