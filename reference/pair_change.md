# The change of LT1 and LT2 in one line each

The change of LT1 and LT2 in one line each

## Usage

``` r
pair_change(x, info)
```

## Arguments

- x:

  The comparison.

- info:

  The `lactater` attribute of the first test, whose LT1 and LT2 are
  followed.

## Value

a character vector named `LT1` and `LT2` (only those chosen by method
and found in both tests).
